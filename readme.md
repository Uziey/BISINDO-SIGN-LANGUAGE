Copy Ini ke terminal terlebih dahulu
  .\.venv\Scripts\python.exe -m pip install --upgrade pip

  .\.venv\Scripts\python.exe -m pip install -r requirements.txt

Jalankan aplikasi penerjemah:
  .\.venv\Scripts\python.exe app.py

Buka http://127.0.0.1:5000 di browser, lalu pilih "Mulai kamera" dan izinkan akses kamera.
Tekan Ctrl+C di terminal untuk menghentikan aplikasi.
